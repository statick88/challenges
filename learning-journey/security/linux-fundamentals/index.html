Resumen de Aprendizaje

Comandos Dominados

Categoría Comandos
Información uname, hostname, whoami, id
Navegación pwd, ls, cd, tree
Archivos touch, mkdir, mv, cp, rm
Búsqueda find, locate, which, grep
Redirección >, >>, <, 2>, \|
Filtrado grep, cut, tr, awk, sed
Procesos ps, top, kill, systemctl
Red ip, ss, curl, wget

Conceptos Clave

  • File Descriptors: STDIN (0), STDOUT (1), STDERR (2)
  • Inodos: Identificadores únicos de archivos
  • Permisos: SUID, SGID, sticky bit
  • Pipes: Conexión entre comandos
  • /etc/passwd: Estructura de usuarios
  • systemd: Gestor de servicios moderno
  • iptables: Firewall de Linux

Lecciones Principales

  1. El shell es poderoso: Dominar pipes y redirecciones multiplica las capacidades
  2. find es esencial: Combinar filtros permite búsquedas precisas
  3. grep + awk + sed: Tríada para procesamiento de texto
  4. systemctl: Control total sobre servicios del sistema
  5. HTB cuenta diferente: Preguntas pueden tener interpretaciones específicas
