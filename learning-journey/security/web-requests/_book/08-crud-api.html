9  CRUD API

Palabras clave

security, web, http, https, api, curl, htb, academy

Las APIs permiten interactuar directamente con bases de datos usando diferentes métodos HTTP.

9.1 CRUD Operations

Operación Método HTTP Descripción
Create POST Agregar datos
Read GET Leer datos
Update PUT Actualizar datos
Delete DELETE Eliminar datos

9.2 API Endpoint Format

http://TARGET/api.php/table/item

9.3 Read (GET)

# Leer item específico
curl http://TARGET/api.php/city/london

# Leer con filtro
curl http://TARGET/api.php/city/le

# Leer todos
curl http://TARGET/api.php/city/

# Formatear JSON con jq
curl -s http://TARGET/api.php/city/london | jq

9.4 Create (POST)

# Crear nuevo item
curl -X POST http://TARGET/api.php/city/ \
  -d '{"city_name":"HTB_City", "country_name":"HTB"}' \
  -H 'Content-Type: application/json'

9.5 Update (PUT)

# Actualizar item existente
curl -X PUT http://TARGET/api.php/city/london \
  -d '{"city_name":"New_City", "country_name":"HTB"}' \
  -H 'Content-Type: application/json'

Nota: PUT actualiza el item completo. PATCH actualiza parcialmente.

9.6 Delete (DELETE)

# Eliminar item
curl -X DELETE http://TARGET/api.php/city/New_City

9.7 Ejercicio Práctico

# 1. UPDATE: Cambiar nombre de ciudad a 'flag'
curl -X PUT http://TARGET/api.php/city/london \
  -d '{"city_name":"flag", "country_name":"HTB"}' \
  -H 'Content-Type: application/json'

# 2. DELETE: Eliminar una ciudad
curl -X DELETE http://TARGET/api.php/city/birmingham

# 3. READ: Buscar ciudad 'flag'
curl -s http://TARGET/api.php/city/flag | jq

9.8 Quick Reference

Operación Método Comando
Create POST curl -X POST -d '{"key":"val"}' -H 'Content-Type: application/json' URL
Read GET curl URL/api.php/table/item
Update PUT curl -X PUT -d '{"key":"val"}' -H 'Content-Type: application/json' URL
Delete DELETE curl -X DELETE URL/api.php/table/item

9.9 Autenticación en APIs

En APIs reales, necesitarías autenticación:

# Con cookie
curl -b 'PHPSESSID=xxx' URL/api.php/city/

# Con Authorization header (JWT)
curl -H 'Authorization: Bearer TOKEN' URL/api.php/city/
