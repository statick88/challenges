1 Prefacio

1.1 Sobre este libro

Este libro documenta el aprendizaje del módulo Web Requests de HTB Academy. Contiene notas detalladas, comandos, ejemplos y la resolución completa de todos los ejercicios.

1.2 Objetivos del Módulo

Al completar este módulo, serás capaz de:

  • Entender el protocolo HTTP/HTTPS y su funcionamiento
  • Analizar requests y responses con cURL y Browser DevTools
  • Manipular headers para interactuar con web applications
  • Usar métodos HTTP (GET, POST, PUT, DELETE)
  • Interactuar con APIs mediante CRUD operations
