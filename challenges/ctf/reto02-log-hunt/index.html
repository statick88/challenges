# Server Log Analysis - Threat Hunting --- 👨‍🏫 **Del Instructor**: Ethical Hacker & Threat Hunter > 🎯 **Mentalidad de Hacker**: _"En un mar de 3000+ líneas de logs, una sola anomalía puede ser la diferencia entre detener una brecha y convertirse en noticia. Los atacantes dejan rastros. Tu trabajo es encontrar la aguja en el pajar digital antes de que sea demasiado tarde."_ --- ## 🎭 El Escenario: Actividad Sospechosa en Servidor de Producción ### Contexto de Blue Team Eres analista de seguridad en una startup de fintech. El WAF (Web Application Firewall) alertó sobre un aumento inusual de tráfico hacia el servidor web principal. Los desarrolladores no reportaron despliegues recientes. El equipo de infraestructura extrae el log completo del servidor web: ``` server.log (3,208 líneas, 108 KB) ``` Revisando manualmente las primeras 100 líneas, todo parece normal. Pero la intuición te dice que algo está oculto. **Tu misión como threat hunter**: 1. Analizar 3,208 líneas eficientemente 2. Identificar patrones de ataque o comportamiento anómalo 3. Extraer cualquier dato exfiltrado o escondido 4. Generar IOCs para detección futura --- ## 🧠 Fundamentos de Análisis: Threat Hunting con Logs ### ¿Qué es Threat Hunting? El **threat hunting** es una práctica proactiva de seguridad donde los analistas buscan amenazas desconocidas o sofisticadas que han evadido las defensas automatizadas. **Diferencia con respuesta a incidentes**: - **IDS/SIEM**: Reactivo (espera alertas) - **Threat Hunting**: Proactivo (busca lo desconocido) ### Tácticas de Ofuscación en Logs Los atacantes sofisticados esconden actividad usando: 1. **Fragmentación**: Dividir datos en múltiples líneas 2. **Timing**: Espaciar actividad para evadir thresholds 3. **Encoding**: Base64, hex, URL encoding 4. **Legitimidad**: Mimetizar tráfico malicioso como legítimo 5. **Volumen**: Ocultar en grandes volúmenes de datos ### Análisis Estadístico de Logs ```bash # Distribución de IPs awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -20 # Distribución temporal awk -F'[:/]' '{print $2":"$3}' access.log | sort | uniq -c # Códigos de estado HTTP awk '{print $9}' access.log | sort | uniq -c | sort -rn # URLs más accedidas awk '{print $7}' access.log | sort | uniq -c | sort -rn | head -20 ``` --- ## 🔍 Metodología de Investigación ### Fase 1: Evaluación del Dataset ```bash # Información básica file server.log wc -l server.log wc -c server.log # Formato del log head -5 server.log tail -5 server.log # Estadísticas de líneas awk '{print NF}' server.log | sort | uniq -c # Campos por línea ``` ### Fase 2: Búsqueda de Anomalías ```bash # Palabras clave sospechosas grep -iE "(error|exception|fail|attack|exploit|union|select|flag)" server.log # Buscar el patrón específico FLAGPART grep "FLAGPART" server.log # Ver frecuencia grep -c "FLAGPART" server.log # Análisis de distribución grep "FLAGPART" server.log | awk '{print $2}' | cut -d']' -f1 | sort | uniq -c ``` ### Fase 3: Extracción de Evidencia ```bash # Extraer todas las ocurrencias grep "FLAGPART" server.log # Eliminar duplicados grep "FLAGPART" server.log | sort -u # Extraer el contenido después de "FLAGPART: " grep "FLAGPART" server.log | sed 's/.*FLAGPART: //' # Versión con cut (alternativa) grep "FLAGPART" server.log | cut -d' ' -f7 ``` ### Fase 4: Reconstrucción de Datos ```bash # Ver el orden temporal grep "FLAGPART" server.log | sort -t'[' -k2 # Extraer timestamps y partes grep "FLAGPART" server.log | awk -F'[][]' '{print $2, $4}' # Reconstruir flag completa grep "FLAGPART" server.log | sort -u | awk '{print $NF}' | tr '\n' '_' | sed 's/_$//' ``` --- ## 🛠️ Arsenal de Herramientas ### Comandos Unix Esenciales | Comando | Propósito | Ejemplo | | ------- | ---------------- | ------------------- | | `grep` | Filtrar patrones | `grep "ERROR" file` | | `awk` | Procesar campos | `awk '{print $1}'` | | `sed` | Transformar | `sed 's/old/new/'` | | `sort` | Ordenar | `sort -t' ' -k2` | | `uniq` | Únicos/conteo | `uniq -c` | | `cut` | Extraer campos | `cut -d' ' -f1,3` | | `tr` | Traducir | `tr '\n' ','` | | `wc` | Contar | `wc -l` | ### One-liners Avanzados ```bash #
